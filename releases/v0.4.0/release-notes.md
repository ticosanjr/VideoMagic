# VideoFlow 0.4.0

Portable, model-free pre-edit pipeline.

## Artifact

- `videoflow-0.4.0-linux-x86_64`
- SHA-256: `e60f0328deb7f7f8f00e2adce7cdca23da222ccd50aae0d6c452590fd627f326`

## Run

```bash
./videoflow-0.4.0-linux-x86_64 doctor
./videoflow-0.4.0-linux-x86_64 demo -o demo
./videoflow-0.4.0-linux-x86_64 run input.mp4 -o project
./videoflow-0.4.0-linux-x86_64 serve
./videoflow-0.4.0-linux-x86_64 mcp
```

Windows assets are built by the `portable` CI workflow on `windows-latest`.
