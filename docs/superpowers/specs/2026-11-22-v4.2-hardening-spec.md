# VideoFlow v4.2 — correção estrutural e faxina

Date: 2026-11-22
Status: proposed
Baseline: v4.1.0
Target executor: DeepSeek v4 no OpenCode

> **Nota de verificação:** os bugs e as contagens de duplicação abaixo são
> hipóteses de auditoria sobre o bundle v4.1.0. Antes de editar ou remover
> qualquer item, confirme com `rg`, leitura do arquivo e teste. Não remova
> testes para fazer a suíte passar.

## TL;DR

O bundle atual (`v4.1.0`) já consolidou `packages/vf-shared/` e migrou os três
antigos MCPs para `src/videoflow/domains/`, mas deixou **cinco bugs silenciosos
verificáveis no código**:

- `alignment.py` retorna RMS `0` em WAV 24-bit;
- `artifacts.py` ignora `exports/qa/`;
- SSE bloqueia threads em `routes_jobs.py`;
- duas pilhas LLM concorrentes sem budget/circuit breaker;
- `STATUS_BY_CODE` incompleto.

Também há **duplicação estrutural severa**:

- 176 arquivos soltos em `application/`;
- dois sistemas paralelos `short_*` vs `shorts_*`;
- estilos duplicados em `presets/` e `src/videoflow/styles/`;
- 12 `recipes/*.json` legadas;
- 43 scripts e wheels `3.17.x–4.0.0` mortos em git.

Esta especificação entrega **seis Microspecs atômicas (P0 → P2)** otimizadas
para DeepSeek v4 no OpenCode.

## 1. Objetivo final e escopo

**Objetivo final:** eliminar bugs silenciosos no core, unificar pilhas
duplicadas (LLM, GPU handlers, MCP, Shorts, Brand Kits), remover código e
binários mortos e padronizar o servidor MCP para execução determinística e com
baixo consumo de tokens no OpenCode, em Linux Mint local com offload GPU Windows
RTX 3060 na LAN.

**Fora de escopo (não alterar nesta especificação):**

- Interface frontend Svelte (`ui/`) e arquivos visuais
  `packages/gpu-worker/src/gpu_worker/ui/*`.
- Lógica de negócio dos exportadores NLE
  (`src/videoflow/exporters/fcpxml.py`, `xmeml/`, `kdenlive/`).
- Algoritmos internos de DSP/DTW em
  `src/videoflow/domains/audio/compare_*.py`.
- Novos efeitos visuais ou alteração de contratos de `presets/*.md` /
  `src/videoflow/styles/*.md` além da consolidação de diretório.

## 3. Contratos, schemas e invariantes

### 3.1. Envelope único de erro MCP (`src/videoflow/mcp_server/guard.py`)

Toda tool registrada no FastMCP deve ser decorada com `@mcp_tool_guard` e nunca
levantar exceção não tratada:

```python
class McpErrorPayload(TypedDict):
    ok: Literal[False]
    error_code: str          # snake_case estável (ex: "invalid_params", "gpu_worker_offline")
    message: str             # frase curta com próxima ação
    invalid_keys: list[str]  # preenchido em pydantic.ValidationError
    did_you_mean: dict[str, str]  # difflib.get_close_matches sobre model_fields
    stderr_tail: str         # últimas 30 linhas se houver subprocesso, senão ""
    fix_hint: str            # ação concreta para o OpenCode
```

### 3.2. Invariante de decodificação PCM 16-bit e 24-bit (`alignment.py`)

```python
def decode_pcm_mono_rms(data: bytes, *, sampwidth: int, channels: int) -> int:
    """Calcula RMS para PCM signed 16-bit (width=2) e 24-bit (width=3).
    Fail-closed: levanta ValueError se sampwidth not in {2, 3}."""
```

- Proibido retornar `0` silenciosamente para `sampwidth == 3`
  (`pcm_s24le`, padrão do `media_contract`).

### 3.3. Contrato de mapeamento HTTP (`src/videoflow/api/errors.py`)

Adicionar obrigatoriamente ao `STATUS_BY_CODE`:

- `"precondition_failed": 412`
- `"gpu_worker_offline": 503`
- `"gpu_required_for_operation": 503`
- `"alpha_channel_missing": 422`
- `"insufficient_contiguous_speech": 422`
- `"beatmap_conflict": 409`
- `"insufficient_disk_space": 507`

### 3.4. Contrato de roteamento remoto fail-closed (`vf_shared/compute/router.py`)

```python
class ExecutionMeta(TypedDict):
    execution_node: Literal["remote_gpu", "local_cpu"]
    worker_url: str
    worker_source: Literal["settings", "mdns", "env", "none"]
    degraded: bool
    degraded_reason: str | None
    vram_peak_mb: int
```

- Se `compute_policy == "remote"` e `/health` falhar em `timeout=1.5 s`:
  levantar `GpuWorkerOfflineError(code="gpu_worker_offline")` (fail-closed).
- Se `compute_policy == "auto"` e cair para CPU: retornar obrigatoriamente
  `degraded=True` e
  `degraded_reason="windows_gpu_offline_fallback_cpu"`.

### 3.5. Contrato de perfis MCP (`src/videoflow/mcp_server/registry.py`)

- `--profile core`: exatamente **16 tools**:
  `vf_project`, `vf_session_brief`, `vf_capabilities`, `vf_ingest`, `vf_run`,
  `vf_transcript`, `vf_decupage`, `vf_scenes`, `vf_preview`, `vf_timeline`,
  `vf_shorts`, `vf_audio`, `vf_media`, `vf_export`, `vf_qa`, `vf_jobs`.
- `--profile full`: exatamente **21 tools** (`core` + `vf_fx_depth`,
  `vf_fx_parallax`, `vf_fx_motion`, `vf_fx_capture`, `vf_style`).
- Docstring obrigatória de 3 linhas por tool:
  `[DOES] ... | [REQUIRES] ... | [RETURNS] ...`.

### FASE P0-1 — Bugs silenciosos no core (PCM 24-bit, QA Store, SSE async e HTTP codes)

**Arquivos da fase:**

- **Ler:** `src/videoflow/core/media_contract/constants.py`,
  `src/videoflow/application/qa_store.py`.
- **Modificar:** `src/videoflow/application/alignment.py`,
  `src/videoflow/application/artifacts.py`,
  `src/videoflow/api/routes_jobs.py`,
  `src/videoflow/api/errors.py`,
  `src/videoflow/application/retakes/clustering.py`,
  `src/videoflow/application/retakes/guards.py`,
  `src/videoflow/application/retakes/similarity.py`.
- **Não tocar:** `src/videoflow/exporters/*`, `packages/*`.

**Passos determinísticos:**

1. Em `src/videoflow/application/alignment.py`, alterar `_Rms.__call__`:
   - `self.width == 2`: manter `array("h")`;
   - `self.width == 3`: decodificar blocos de 3 bytes signed little-endian
     (`int.from_bytes(chunk, "little", signed=True) >> 8` para escalar ao mesmo
     domínio de 16-bit do `threshold=400`);
   - `self.width not in {2, 3}`: lançar
     `ValueError(f"Unsupported PCM sample width: {self.width}")`.
2. Em `src/videoflow/application/artifacts.py`, atualizar `qa_artifacts()` para
   também iterar `sorted((output / "exports" / "qa").glob("*.json"))` quando o
   diretório existir, agregando cada relatório em `reports[path.stem]` e seus
   `issues` em `defects`.
3. Em `src/videoflow/api/routes_jobs.py`, converter `_job_event_stream` para
   `async def _job_event_stream(job: Job) -> AsyncIterator[str]`, substituindo
   `time.sleep(0.2)` por `await asyncio.sleep(0.2)`.
4. Em `src/videoflow/api/errors.py`, adicionar os sete códigos da Seção 3.3 em
   `STATUS_BY_CODE`.
5. Em `src/videoflow/application/retakes/{clustering,guards,similarity}.py`,
   importar a constante de sample rate de
   `videoflow.core.media_contract.constants`, substituindo todos os literais
   `48000` / `48_000`.
6. Criar/atualizar testes unitários em `tests/unit/test_alignment_24bit.py` e
   `tests/unit/test_qa_artifacts_and_errors.py`.

**Refatoração/limpeza acoplada:** remover `import time` de `routes_jobs.py` se
não for mais usado após migrar para `asyncio.sleep`.

**Edge cases obrigatórios:**

- Buffer WAV 24-bit com tamanho não múltiplo de `3 * channels`: truncar o resto
  incompleto antes de decodificar, sem `IndexError`.
- JSON corrompido em `exports/qa/`: registrar `{"error": "unreadable"}` sem
  abortar `qa_artifacts()`.

**Validação:**

```bash
uv run pytest tests/unit/test_alignment_24bit.py tests/unit/test_qa_artifacts_and_errors.py tests/unit/test_retakes*.py -q
```

**Critério PASS:** `0 failed`; teste prova RMS > 0 em WAV 24-bit sintético e
`qa_artifacts()` lê `exports/qa/*.json`.
