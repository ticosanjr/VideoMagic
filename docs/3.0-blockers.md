## Voice cloning

Voice cloning is **optional and implemented**. The default provider is `none`.
With `VIDEOWFLOW_VOICE_CLONE_PROVIDER=elevenlabs` and `ELEVENLABS_API_KEY`, the
`voice.clone` step accepts an approved profile, stores consent and local
reference samples, and synthesizes a repair clip. Without a provider, the
patch/TTS fallback remains. See [voice-clone.md](voice-clone.md).

## Resolved debt

The runner no longer merges ambient domain state. `artifacts`, `metadata`,
`shorts`, `selected_shorts`, `short_captions`, transcript changes, and speech
spans cross steps only through declared output ports. The runner keeps hashes,
cache bookkeeping, and warnings as diagnostics because they are not domain data.
