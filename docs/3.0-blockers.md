## Open blockers

### 1. Manual NLE QA

Resolve, Premiere, and Kdenlive are not installed on this machine
(`which kdenlive melt` is empty). Automated structure validation passes, but the
plan requires a human to open the exports and check titles, colour, audio,
B-roll, chapters, transitions, and clicks.

Required evidence: `docs/nle-qa.md` signed per NLE, with a job id and the exact
export folder.

### 2. Manual assistive-technology QA

Orca is installed and `DISPLAY=:20` exists, but no human has signed the
keyboard/screen-reader/zoom-200%/contrast checklist. Automated keyboard, focus,
narrow viewport, locale, and reduced-motion tests are green.

Required evidence: `docs/accessibility-qa.md` signed.

### 3. Full-tree coverage ≥95%

Current full-tree coverage is **81.7%** (19,292 statements, 3,540 missed). The
per-layer targets now pass: API 85.2%, jobs 90.8%, exporters 95.0%, MCP 80.3%.
The configured gate covers `videoflow.domain`, the cache, and the timeline
builder at 98.7%. Raising the whole tree to 95% still needs roughly 2,600
additional covered statements, mostly in adapters, step runners, CLI, services,
and external integrations. That is a separate, large testing project, not a
release formality.

Required evidence: a full-tree report at or above 95% with the same command used
for the 3.0 gate. The current report is in [coverage.md](coverage.md): API
85.2%, jobs 90.8%, exporters 95.0%, MCP 80.3%, full tree 81.7%.

### 4. Voice cloning

No configured provider exposes a voice-clone endpoint. The decision is recorded
in [voice-clone.md](voice-clone.md): keep the existing TTS/dubbing fallback and
defer cloning until a provider with an explicit clone contract is approved.

## What is safe to claim

- 3.0 is blocked by the four items above, not by missing application code.
- No artifact was pushed, published, or signed.
