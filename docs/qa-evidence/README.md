# QA evidence

These files are generated by `scripts/qa_evidence.py`. They collect:

- structural NLE validation (FCPXML, XMEML, Kdenlive);
- the installed Kdenlive/Flatpak version;
- a non-interactive MLT render through the Flatpak `melt`;
- Orca and display availability;
- the automated commands and visual baselines that support the manual pass.

They are **not** sign-offs. The `signoff` block stays empty until a human
reviews the Kdenlive import and the accessibility checklist and fills in
`docs/nle-qa.md` and `docs/accessibility-qa.md`.

Regenerate with:

```bash
uv run python scripts/qa_evidence.py \
  --exports build/smoke-appimage/demo/exports \
  --job-output build/smoke-appimage/demo
```
