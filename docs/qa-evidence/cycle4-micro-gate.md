## What this run caught

The 7-minute fixture exposed two Shorts bugs:

1. `crossfade_ms=0` from the batch spec was overridden by the tightened
   metrics, sending the render into the chained `xfade` path. The `xfade`
   offset accumulator drifted, so the video stream stopped after the second
   piece while audio continued.
2. The final audio pass targeted the piece-sum duration instead of the rendered
   video duration, leaving a ~0.05–0.10 s A/V drift.

Both are fixed: the spec crossfade is honored, `xfade` uses the actual previous
output duration, and the final loudness pass pads/trims audio to the probed
video duration. A failed duration/media gate is now raised instead of silently
deleting the file and keeping the clip in the manifest.
